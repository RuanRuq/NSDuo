StikJIT is licensed under MPL-2.0. NS Duo modifies ScriptRunner to retain all
64 address bits and validate every debugserver page-write response. Modified
MPL-2.0 source files are provided at tools/nsduo/stikjit. The reproducible local
build entry point is tools/nsduo/build-stikjit.py. NS Duo also supplies the
missing framework Info.plist using upstream project.yml metadata. The helper
and IPC bridge are NSDuo integration code; no Husk implementation was copied.

NS Duo additionally provides PairingHostRuntime.swift, an independently written
adapter to the bundled idevice pairable-host API for iOS 27+ first pairing.
The adapter is at tools/nsduo/stikjit/PairingHostRuntime.swift. The host loads
only this pairing entry point on demand; debugger operations remain in the
separate helper. No StikPair application source was copied or bundled.

Bundled idevice FFI is by Jackson Coxson and contributors:
https://github.com/jkcoxson/idevice (MIT).
The StikJIT release does not identify the exact revision of its bundled idevice
static archive. NSDuo retains that archive unchanged in the source snapshot.

The original universal.js and legacy.js scripts retain the license of their
StikDebug upstream (AGPL-3.0): https://github.com/StikDebug/StikDebug
Their exact bundled sources are included in the archive above and separately
in distribution/legal/StikJIT. StikJIT is a separate library from StikDebug.
