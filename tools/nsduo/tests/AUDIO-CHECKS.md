# SDL3 音频主机回归

从工程根目录运行 `python3 tools/nsduo/tests/run-audio-checks.py`。使用工程内 .NET，输出保存在 `work/audio-checks`，不构建 iOS App、不打开音频设备。

测试编译生产 SDL3 session、音频环形缓冲、采样计数及内存池实现，仅替换 SDL 和宿主驱动边界。在临时生成的 session 源码中插入两个调度钩子，强制音频回调在 PCM 写入后、完成记录入队前到达，检查回调等待完整发布且采样计数、缓冲完成及通知一致。可用 `NSDUO_AUDIO_SOURCE_ROOT` 指定旧源码根目录，复现旧实现丢记账的失败。

同时检查完整音量的三种有符号整数 PCM 格式逐字节保真、只租借一个输出缓冲且不调用混音；浮点 PCM 保留 SDL 混音路径，以保留其裁剪及特殊值行为，欠载尾部为零；部分/静音音量仍经过 SDL 混音边界并正确消费，跨缓冲完成、空队列及启动/暂停/恢复/关闭行为不变。

这些检查证明内存队列与控制流正确，不代表真实 SDL 的混音算法、音频硬件时延、真机爆音或帧率已验证。
